Server riêng là gì, vì sao Vector cần?

Vector không tự hiểu giọng nói. Robot thu âm câu bạn nói, gửi tới một máy chủ (server) để chuyển thành chữ và hiểu ý, rồi nhận câu trả lời về.

Hãng Anki đã ngừng hoạt động, nên máy chủ gốc do công ty kế nhiệm quản lý. Máy chủ đó từng yêu cầu thuê bao và có lúc gián đoạn, khi ấy Vector không nghe lệnh được.

Server của hãng

Bạn phụ thuộc vào hãng: phí thuê bao, bảo trì, ngừng dịch vụ.

Server riêng của bạn

Chạy ở nhà, do bạn quản lý. Dùng Wire-Pod, phần mềm mã nguồn mở miễn phí của cộng đồng, và có thể chuyển câu hỏi sang model AI.

Server cần một thiết bị chạy cùng mạng với robot, như máy tính cũ hoặc Raspberry Pi. Mình tư vấn phương án gọn nhất khi báo giá.

Câu hỏi thường gặp

Vector bản nào cũng cài server được không?

Wire-Pod hoạt động với cả Vector 1.0 và 2.0. Bạn nhắn tên bản và tình trạng robot để mình xác nhận trước khi báo giá.

Server có cần chạy liên tục không?

Có. Robot cần server bật và cùng mạng để nghe lệnh. Một máy tính cũ hoặc Raspberry Pi là đủ. Mình tư vấn phương án gọn và tiết kiệm điện cho bạn.

Chi phí thế nào?

Tùy việc bạn chọn: sửa phần cứng, cài server, kết nối AI hay Việt hóa giọng nói. Mình báo giá sau khi biết tình trạng robot.
